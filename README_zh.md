## 📖 关于模组 (About)

**《Mechanized（机械纪元）》** 是一个结合了**手动工件组装**与**异维度冒险**的 NeoForge 科技冒险模组。

在这里，做装备不再是把材料丢进九宫格或者放进机器挂机等待，而是像现实里的硬件创客一样——在技师工作台上用锯子裁切晶片基板、用电焊枪点焊走飞线、拿锤子敲打冲压外壳，亲手组装出一枚搭载多功能插槽的“天幕手环”。

戴上手环，你可以随身搭载推进、挖掘、磁吸、护盾等各种模块。随着探索深入，修好主世界遗迹里的时空传送门，你将踏入失落的机械维度 **“机械纪元 (The Mechazoic)”**，在生化与齿轮构成的世界中探寻更高阶的机械核心与技术蓝图。

## 🌟 核心玩法与系统 (Features)

### 🛠️ 纯世界交互：技师工作台 (Machinist Bench)
* **无 GUI，纯手动操作**：原料直接摆放在工作台表面，直观可见；
* **多工序序列拼装**：通过手持锯子裁切、电焊枪点焊引脚、钢锤冲压定型等一系列连贯的手动操作，亲手将零散材料组装为精密构件；
* **废品熔炼回收**：如果不小心弄错工序步骤会产生金属废品，丢进回收炉就能按比例熔回原料，不必担心试错成本。

### ⭕ 随身核心：天幕手环 (Space Dome)
手环是整套玩法的核心载体，戴在手腕上，支持随时插拔各种功能模块：
* **【轻量天幕手环 (Lite)】**：主世界手搓版。受限于主世界材料，以钢和铜仿造而成，消耗通用 FE 电能；
* **【制式天幕手环 (Common)】**：机械纪元原生规格。脱离主世界兼容层，原生消耗高阶源质能量，提供更多插槽；
* **【始初天幕手环 (Prime)】**：异星领袖规格。击败统治者 BOSS 获得核心蓝图升格而成，拥有顶级性能与扩展上限；
* **【创造天幕手环 (Creative)】**：创造模式专属，无限能量与插槽。

手环可搭载推进冲刺、便携挖掘、磁吸、护盾等多种模块，通过长按快捷键呼出环形轮盘即可随时切换。

### 💧 奇特能源：源质 (Zoetium) 与辉源花
* **辉源花 (Zoetic Bloom)**：主世界地表自然生长，可用机器抽取其中的源质能量，抽完后会退化为枯木；
* **地下源质池**：辉源花正下方通常深埋着一潭半透明青蓝色（#06D5F9）的液态源质。初次跌入源质中会得到灵感，解锁初级手环的制作方式；
* **双轨能源过渡**：前期使用基础燃料发电机与充电台（标准 FE 电能，兼容主流科技模组电缆），后期进入机械纪元后可解锁超视距的**无线能量共鸣塔**。

### 🌌 异星探险：机械纪元 (The Mechazoic)
* **寻找废弃实验室**：主世界会自然生成罕见的机械实验室遗迹。合成**异常信号定位仪**（不会碎裂，自带方向感应）能轻松循着信号找到它；
* **修复传送门**：取下传送门上损坏的芯片，带回基地修复后插回，灌入一桶源质完成一次性点火，即可长久开启通往机械纪元的大门；
* **高难挑战与领袖图纸**：在机械废墟中击败各区域守护者，收集失落科技，最终战胜统治者夺得始初手环图纸。

### 🤖 硅基奇迹：机生种 (Mechazoa) 与仿灵械兽
* **自然演化的硅基生命**：机械纪元的原生生物并非冰冷的人造机器，而是吸收金属与源质亿万年演化而来的**机生种 (Mechazoa)** 与**灵械兽 (Mechazoan)**。金属外骨骼与齿轮铰链，恰如地球生物的骨骼与甲壳；
* **手搓复刻与变形折叠**：玩家在技师工作台上逆向解析后，可用机械板件手搓出专属于自己的**仿灵械兽 (Mechazoan Replica)** 机械仆从。当其能量耗尽或被召回时，会像变形金刚一样精密折叠闭锁成 1x1 方块立方体；
* **仿械仓 (Replica Cradle)**：将立方体滑入基地仿械仓，即可实现快速充电、自适应构件修复与轻量化物料调度。

## 🗺️ 游玩推进路线 (Progression)

1. **奇想初萌 (Early Days)**  
   寻找地表生长的辉源花与深埋地底的半透明源质池，获得制作灵感；利用高炉炼制基础钢材与单晶硅。

2. **创客工坊 (The Machinist)**  
   搭建技师工作台，亲手裁切基板、焊接走线组装轻量天幕手环 (Lite)；制造智能分析仪逆向解析基础插件模块。

3. **搜寻信号 (The Signal)**  
   装配智能目镜，手持异常信号定位仪循着电磁波动，在主世界地底深处找到失落的废弃机械实验室。

4. **纪元飞升 (The Mechazoic)**  
   修复芯片激活传送门踏入机械纪元；探秘机生种自然生态，手搓变形仿灵械兽仆从与仿械仓；战胜机械统治者夺得领袖图纸，升格始初天幕手环 (Prime)。

## ⚙️ 配置文件与整合包支持 (Configuration)

模组内置详细的服务器端配置，所有关键平衡参数均未硬编码，整合包作者可按需自由调整：
* `config/mechanized-server.toml` 支持调节：发电机发电速率、废品回收成功率、各阶手环模块槽位数量、工具耗电量等；
* 原生支持 DataPack 自定义工作台装配配方。
